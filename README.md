# STM32F411 Motor Control

STM32F411(Cortex-M4)에서 **UART 명령과 버튼 입력으로 모터의 회전 방향, 정지, PWM 듀티를 제어하는 펌웨어**입니다. CMSIS 장치 헤더와 레지스터 직접 접근을 사용하며, HAL이나 RTOS 없이 동작하도록 구성되어 있습니다.

> 이 문서는 저장소의 소스코드를 기준으로 작성했습니다. 실제 보드에서 빌드·구동한 결과는 아니며, 보드 모델과 모터 드라이버 모델은 저장소에 명시되어 있지 않습니다.

## 주요 기능

- CW / CCW 회전 및 정지 제어
- TIM5의 두 채널을 이용한 PWM 출력(코드 요청값: 10 kHz)
- UART 숫자 명령으로 PWM 듀티 단계 조절
- 버튼을 짧게 눌러 시작 또는 회전 방향 전환
- 방향 전환 시 약 1초 동안 정지한 후 반대 방향 구동
- 버튼을 길게 눌러 정지
- USART2를 통한 상태 및 디버그 메시지 출력

PWM 듀티를 조절하는 개방 루프 방식입니다. 엔코더를 통한 실제 회전수 측정이나 PID 속도 제어는 구현되어 있지 않습니다.

## 하드웨어 및 핀 구성

대상 MCU는 Makefile의 `STM32F411xE` 정의를 기준으로 합니다. 시스템 클록은 코드상 96 MHz, APB1 클록은 48 MHz로 설정됩니다.

| 핀 / 주변장치 | 코드상 용도 |
| --- | --- |
| PA0 / TIM5_CH1, AF2 | 모터 제어 출력 1: CCW 시 PWM, CW·정지 시 LOW |
| PA1 / TIM5_CH2, AF2 | 모터 제어 출력 2: CW 시 PWM, CCW·정지 시 LOW |
| PA2 / USART2_TX, AF7 | 시리얼 상태 메시지 출력 |
| PA3 / USART2_RX, AF7 | 시리얼 명령 수신 |
| PC13 / EXTI13 | 버튼 입력: LOW가 눌림, 양쪽 에지 인터럽트 사용 |
| PA5 | LED 출력 초기화, 현재 제어 루프에서는 상태 표시로 사용하지 않음 |
| PA13 / PA14 | 시작 코드에서 디버그용 핀 설정 잠금 |
| TIM2 | 버튼 누름 시간 측정, 최대 약 3초 |
| TIM4 | 방향 전환 전 약 1초 정지 시간 |
| TIM5 | 모터 PWM 생성 |

PA0·PA1은 모터 드라이버의 논리 입력에 연결하는 신호입니다. 모터를 MCU 핀에 직접 연결하지 말고, 사용하는 드라이버의 입력 방식·전압·전원·공통 GND를 확인해야 합니다. 실제 CW/CCW 방향과 정지 시 브레이크/코스트 동작은 드라이버 및 배선에 따라 달라집니다.

## UART 사용법

시리얼 터미널을 **115200 baud, 8 data bits, no parity, 1 stop bit, flow control 없음**으로 설정합니다. 명령은 한 문자씩 처리하므로 줄바꿈 없이 전송하는 것이 편리합니다.

| 명령 | 동작 |
| --- | --- |
| `F` / `f` | CW 회전. CCW 구동 중이면 약 1초 정지 후 CW로 전환 |
| `R` / `r` | CCW 회전. CW 구동 중이면 약 1초 정지 후 CCW로 전환 |
| `S` / `s` | 정지 요청 |
| `0` | 정지 요청 |
| `1` ~ `9` | 듀티 단계 설정: 계산식 기준 50% ~ 90%, 5%p 간격 |

듀티 계산식은 `45 + 5 × 단계`(%)이며 기본 단계는 `1`(50%)입니다. 숫자 `0`은 듀티 0% 설정이 아니라 정지 명령입니다. 정지 상태에서 `1`~`9`를 보내면 다음 구동에 사용할 듀티가 저장됩니다.

예시: `F` → `5` → `R` → `S`

CW 구동 → 듀티 70% → 약 1초 정지 후 CCW 구동 → 정지 요청 순서입니다. 상태 로그에 `start`, `cw`, `ccw`, `Motor Stop` 등이 출력됩니다.

## 버튼 사용법

아래 시간은 상수와 분기 조건을 기준으로 한 의도된 동작입니다. 반복 입력 및 UART와의 동시 사용에는 아래 구현상 주의사항이 적용됩니다.

| 입력 | 동작 |
| --- | --- |
| 약 900 ms 이하로 눌렀다가 놓기 | 정지 상태이면 CW 시작, 회전 중이면 약 1초 정지 후 방향 전환 |
| 약 900 ms 초과 ~ 2100 ms 미만 | 제어 동작 없이 대기 상태로 복귀 |
| 약 2100 ms 이상 누른 뒤 놓기 | 정지 요청 |
| 약 3초 동안 계속 누르기 | TIM2 만료 인터럽트로 정지 요청 |

## 동작 흐름

1. 클록, UART, LED, 버튼, 모터 출력, 타이머를 초기화합니다.
2. 모터를 정지 상태로 두고 UART 수신 및 버튼 인터럽트를 활성화합니다.
3. 인터럽트에서 입력을 해석하고 모터 상태 또는 버튼 상태를 갱신합니다.
4. `Main()` 반복문에서 상태 변경을 감지해 모터 출력을 적용합니다.
5. 방향 전환 요청은 출력을 먼저 정지하고 TIM4 만료 후 방향 상태를 바꾸는 방식으로 처리합니다.

## 빌드 및 다운로드

### 준비 사항

- Arm GNU Toolchain: Makefile 기본 설정은 15.2.1
- Windows용 Make 실행 환경 및 `rm` 명령(`make clean` 사용 시)
- STM32CubeProgrammer CLI 및 SWD 디버거
- 대상 보드에 맞는 링커 스크립트

**현재 저장소에는 Makefile이 참조하는 `rom_0x08000000.lds`가 없습니다.** 따라서 새로 내려받은 상태에서 링크까지 완료하려면 해당 파일을 먼저 준비해야 합니다. `crt0.s`와 `option.h`에서 참조하는 `__RO_LIMIT__`, `__RW_BASE__`, `__ZI_BASE__`, `__ZI_LIMIT__` 심볼과 대상 MCU의 메모리 배치를 함께 확인하세요.

### 실행 순서

1. Makefile의 `TOOL_DIR`와 `VERSION`을 설치된 도구 경로에 맞춥니다.
2. 프로젝트 루트에 `rom_0x08000000.lds`를 준비합니다.
3. 프로젝트 루트에서 빌드합니다.

```sh
make
```

빌드가 성공하면 `rom_0x08000000.elf`, `rom_0x08000000.bin`, `rom_0x08000000.map` 및 덤프 파일이 생성됩니다.

4. SWD 디버거를 연결하고 `STM32_Programmer_CLI.exe`가 PATH에 있는 환경에서 다운로드합니다.

```sh
make run
```

`run` 대상은 기존 ELF 파일을 SWD로 기록·검증하고 리셋합니다. 자체 빌드 의존성이 없으므로 먼저 `make`를 완료해야 합니다. Makefile의 경로 표기는 Windows 환경을 기준으로 작성되어 있습니다.

## 현재 구현상 주의사항

- **버튼 누름 시간 초기화:** `btn_holding_time`은 계산 후 다음 누름에서 0으로 초기화되지 않습니다. 첫 측정값이 이후 판단에 재사용될 수 있습니다.
- **방향 전환 중 정지 명령:** TIM4 대기 중 `Uart_Data_In`이 1이면 UART 입력을 읽고 버립니다. 버튼으로 시작한 방향 전환 대기와 UART 입력이 겹치는 경우에도 대기 타이머 취소 처리가 없어, 정지 요청 후 방향 상태가 다시 변경될 수 있습니다. 현재 명령 처리를 비상 정지 기능으로 사용해서는 안 됩니다.
- **입력 간 상호 배제:** 버튼 누름과 UART 명령이 공유 상태를 수정하며, 버튼 누름 중 UART를 비활성화하는 처리는 구현되어 있지 않습니다.
- **버튼 디바운싱:** 별도의 접점 바운스 제거 처리는 명확하게 구현되어 있지 않습니다.
- **인터럽트 내 출력:** 여러 인터럽트 핸들러에서 `printf`를 호출하므로 시리얼 출력량에 따라 입력 처리 지연이 생길 수 있습니다.
- **검증 범위:** 문서 작성 시 소스코드만 확인했습니다. 실제 PWM 주파수·파형, 배선, 버튼 시간, 빌드 성공 여부는 보드에서 별도로 검증해야 합니다.
